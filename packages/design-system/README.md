# Arqen Design System

The design system is the canonical visual language consumed by the renderer and, later, the code compiler.

## Foundations

- typography scale and text roles
- semantic color tokens
- spacing scale
- shape/radius tokens
- elevation
- motion
- icon sizing
- responsive breakpoints

## Component philosophy

Components encode product behavior and states, not just visual decoration. Every major component should define its default, loading, empty, error, disabled, and responsive behavior where applicable.

The system should remain restrained, highly legible, and adaptable to the product being built. Avoid template-specific styling leaking into the canonical tokens.
