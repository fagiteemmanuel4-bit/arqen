# Arqen Product Vision

## What Arqen is

Arqen is an AI-native product engineering environment. It is not primarily a prompt-to-website generator. Its core job is to translate human product intent into structured, coherent software artifacts.

## Initial wedge

The first public capability is **Design Intelligence**.

A user describes a product. Arqen should reason about the product structure, define the UX architecture, establish a design language, create a UIIR representation, render an editable prototype, and eventually export clean React/TypeScript code.

## Core pipeline

```text
Human intent
  ↓
Product understanding
  ↓
UX architecture
  ↓
Design system
  ↓
UIIR
  ↓
Interactive renderer
  ↓
React/TypeScript output
```

## What we are deliberately not doing first

- Full backend generation
- Autonomous production deployment
- Multi-agent software organization
- Unrestricted code execution
- Trying to clone an existing AI builder

Those become later capabilities once the core representation and verification model are strong.

## Product standard

Arqen should produce work that looks intentionally designed, behaves coherently across screen sizes, uses reusable primitives, handles edge states, and remains understandable to a human engineer.
